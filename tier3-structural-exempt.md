# tier3-structural-exempt.md — pages out-of-scope for the §XVI Sapiential Standard

Generated by `tier3-inventory.js` in S68 (Sapiential Deepening Run, Leg 9). Once a page lands here, no future session needs to re-investigate whether it requires the §XVI sapiential bar — it does not, because it is not a prose doorway. Hubs, utility shells, JS-driven explorers, printables, and the few legacy index pages that survived the cleanup.

The script bucket-A classifier looks for two signals:
1. The page lacks `<article class="article-body">` (so it is auto-excluded from the prose set the audit walks).
2. The page name matches an explicit allowlist of structural / utility / index / printable patterns.

Because (1) auto-excludes most hubs from Tier-3 to begin with, BUCKET A within Tier-3 is small — only the rare prose-shaped page that is functionally a hub or directory. Both are pre-existing hub-like pages that retain an article-body wrapper but serve as living indices rather than apologetic prose.

## Standing rule

Future sessions: if a page lands in BUCKET A in any later inventory run, do not re-audit it for §XVI. The structural exemption is documented and final. If a structural page is upgraded into a prose doorway (real argument, not directory), it must be re-classified explicitly in this file and re-routed to BUCKET B/C/D.
