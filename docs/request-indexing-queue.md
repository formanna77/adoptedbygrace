**Built:** 2026-06-10 (S108, Campaign 3 Lane 1) · **Owner of the clicks:** Aaron · **Quota:** GSC allows roughly 10 URL-inspection submissions per day, so this is a three-day queue.

## How to submit (2 minutes per URL)

1. Open [Google Search Console](https://search.google.com/search-console) for the `adoptedbygrace.net` property.
2. Paste the full URL into the **URL Inspection** bar at the top.
3. Wait for the report, then click **Request Indexing**. (If it says "URL is on Google," skip it and move down the list — do not waste quota.)
4. Mark the date in the table below so the next session knows where the queue stands.

Request-indexing pushes a page into the priority crawl queue; Google still decides whether to index based on trust. This is the nudge — the backlink plan is the cure. Every URL below is verified to exist on disk as of today.
